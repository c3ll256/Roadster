# Roadster 车牌挂坠

本体72×38×3.5 mm，四角R3，左侧凸出一体挂绳孔，纯机械挂坠。

## 外观要求

银灰牌面，主文字RDSTR与连续细边均为深蓝色。主文字保留既有粗笔画字形与圆润浮雕，按用户要求缩小；上方增加红色“Hangzhou”，参考用户提供的California字样采用倾斜、连笔的笔刷手写体。文字拼写为Hangzhou。

周围保留圆弧下凹槽，凹槽内侧过渡弧度大于外侧，两侧与平面相切，槽底连续。左侧挂耳根部保留双侧相切圆弧。

## 已披露默认值

72 mm不含左侧挂耳，总长78 mm。RDSTR字组缩小20%，宽33.712 mm、高12.4 mm，中心Y=-3.8 mm；顶面R0.45圆角，浮雕高0.6 mm。Hangzhou采用Brush Script MT Italic，高7.15 mm、自然宽约25.79 mm，中心Y=8.8 mm，浮雕高0.4 mm。两行包络竖直间距约2.825 mm。主文字至凹槽内侧平面边界左右各约16.59 mm、下方约6.45 mm；小字上方约4.073 mm。

深蓝默认#17365D，红色默认#D51F2A，牌面银灰#BFC1C4。边沿宽0.7 mm、深0.6 mm，顶面与牌面同高。三色共打印，各颜色区域只接触、不重叠，合并后为一体挂坠。

挂孔直径4 mm，挂耳外径8 mm、径向壁宽2 mm、厚3.5 mm，根部双侧默认R2。圆弧凹槽深0.45 mm、槽底R0.45、外侧过渡R0.35、内侧过渡R1.2；槽宽约1.85 mm。最大厚度4.1 mm。四角对称设置平底圆形盲孔，深0.5 mm；按标注大小默认直径1.8 mm，孔心默认X=±26 mm、Y=±13.5 mm，孔底余厚3.0 mm。

## 合并版

同时提供一个单实体合并版本，全部底板、细边及两行浮雕文字以布尔并集成为一个有效实体，四角盲孔和挂绳孔保留。合并版从原模型生成，几何与尺寸一致，默认银灰色显示；分色版保留三色材料区域。默认合并版向右移90 mm，两版最近外形间距12 mm，便于并排比较和单独导出。

## 制作与验收

默认相同材质PETG三色共打印，平背朝下，建议层高0.1–0.15 mm，无需支撑。细小手写笔画需精细切片；也可单色打印后手工上色。挂绳自备。未做实物试打或承载测试。

检查上红下蓝的两行居中排版、手写连笔风格及深蓝连续边沿；检查四角盲孔镜像对称、直径1.8 mm、深0.5 mm，孔底不贯穿；检查三种颜色分区不重叠且合并为单一有效实体、总包络78×38×4.1 mm、4 mm通孔和根部R2。交付可编辑参数与当前三色STEP。

新上传的California字样可直接校对。此前上传的车牌照片、RDSTR高清图与挂耳标注图目前缺失，保留已经建模的字形、凹槽与接口几何。
