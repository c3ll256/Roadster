# RDSTR / Hangzhou 车牌挂坠（分色版与合并版）

## 目的与参考

本体72×38×3.5 mm，平面四角R3，银灰色牌面及挂耳；深蓝RDSTR和闭合细边，上方为红色手写Hangzhou。用户提供的California字样用于笔刷连笔、倾斜风格参考；文字按用户指定改为Hangzhou，使用运行环境中已确认存在的Brush Script MT Italic字体。字体是近似风格实现，不是从California图中推导出未出现字母的精确描摹。

此前plate_front、plate_alternate、rdstr_lettering、plate_spacing、eye_root_transition原上传图当前缺失，保留既有参数化轮廓与接口。

## 两行排版与颜色

RDSTR相对原字组宽高均缩小20%，宽33.712 mm、高12.4 mm，中心Y=-3.8 mm，浮雕高0.6 mm，顶面R0.45。保留粗笔画、字距比例、R斜腿、D圆肩与S曲线。文字到内侧平面边界左右各约16.59 mm，下方约6.45 mm。

Hangzhou字形包络高7.15 mm，自然宽约25.79 mm，中心Y=8.8 mm，浮雕高0.4 mm，上方净距约4.073 mm；到主字组的竖直间距约2.825 mm。两行均按实际字形包络居中。

默认银灰#BFC1C4、深蓝#17365D、红色#D51F2A。四个共打印几何对象分别是银灰底板、深蓝细边、深蓝RDSTR、红色Hangzhou。主文字含五个字母实体，小字连笔后为两个实体，全部从底板表面起凸；这些是同一挂坠的材料区域，不是单独装配的零件。合并后为单一有效连通实体，各区域无体积重叠。

## 凹槽与边沿

原有圆弧下凹槽保留：外侧平边0.7 mm、槽深0.45 mm，外侧过渡R0.35、槽底R0.45、内侧过渡R1.2，槽宽约1.85 mm，槽底最薄处3.05 mm。相切圆弧连接两侧同高平面。深蓝色带宽0.7 mm、深0.6 mm，随R3外轮廓闭合，顶面与牌面同高。

## 四角圆形盲孔

按用户标注位置镜像设置四个平底盲孔，孔心默认X=±26 mm、Y=±13.5 mm。孔径按标记大小默认1.8 mm，深度按用户要求为0.5 mm，孔口在Z=3.5 mm，孔底Z=3.0 mm，保留3.0 mm底厚。相对车牌本体中心左右、上下对称；用于车牌外观细节，不作为螺纹连接。

## 接口

cord_eye：左侧中部一体挂耳外径8 mm、通孔4 mm、自由环段径向壁宽2 mm、厚3.5 mm。圆心在本体左边向外2 mm，净凸出6 mm。根部双侧R2相切过渡并局部加宽。总包络78×38×4.1 mm。

## 单实体合并版

合并版读取原挂坠的完整布尔并集，底板、边沿、RDSTR及Hangzhou共用一个有效连通实体，保留圆弧槽、挂绳孔及四角盲孔。对象为“合并版挂坠”，默认银灰色显示；原四个对象继续作为分色版本提供。合并版的merged_scale为统一缩放比例，默认1，尺寸与原版一致；保持1即可原尺寸导出。

合并版在同一设计中向右平移90 mm，原版最右端X=36 mm、合并版最左端X=48 mm，两版间隔12 mm。它读取原模型而不复制字形代码，原模型几何修改后会同步重建合并版。

## Making and assembly

相同材质PETG三色共打印，平背朝下，建议层高0.1–0.15 mm，无需支撑。分色版的四个对象按原坐标作为同一模型的材料区域进入切片器，不可分散排版。合并版可单独导出为一个实体用于单色打印或后期上色；两版是替代版本，不需组装在一起，打印一枚挂坠时只导出所选版本。小字笔画较细，需精细切片；尚未以特定喷嘴尺寸验证。单色设备可打印整体后手工上色，仅按高度换色不能分别获得同层的红字、蓝字和蓝边。挂绳自备，穿过4 mm通孔系结。未做实物试打或承载测试。

## 验收

检查四个圆孔的实际圆柱孔壁、1.8 mm直径及0.5 mm深度，确认孔底保留3.0 mm底厚及孔心双轴镜像对称。正视检查Hangzhou拼写、红色连笔小字位于缩小的深蓝RDSTR上方，两行居中；边沿深蓝且连续。检查实际字形包络、行距、4 mm通孔、根部R2和78×38×4.1 mm包络；四个对象不重叠，合并为单一有效实体。合并版检查单一有效实体、体积与原版并集一致、包络尺寸不变，且与原版无干涉。交付包含分色版与旁置合并版的当前STEP并刷新预览，可按对象单独导出。
